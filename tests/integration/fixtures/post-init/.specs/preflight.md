# Preflight Checklist

## Tooling

- [x] Node.js 20+ installed
- [x] TypeScript 5.x compiler available
- [x] PostgreSQL 16 running locally or via Docker
- [x] Package manager (npm) configured

## Authentication

- [x] JWT signing key generated and stored securely
- [x] Password hashing library (bcrypt) selected and tested
- [ ] OAuth provider credentials (deferred to post-MVP)

## Tokens

- [x] Anthropic API key available for LiveSpec operations
- [x] GitHub personal access token for CI integration
- [ ] Sentry DSN for error tracking (optional, post-MVP)
