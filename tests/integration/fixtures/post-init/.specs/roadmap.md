# Roadmap

## MVP

<!-- roadmap:mvp:start -->
- [ ] **User Authentication** — Email/password login with JWT tokens and session management
- [ ] **Task CRUD** — Create, read, update, and delete tasks with title, description, status, and assignee
- [ ] **Sprint Board** — Kanban-style board showing tasks grouped by status within the active sprint
<!-- roadmap:mvp:end -->

## Post-MVP

<!-- roadmap:postmvp:start -->
- [ ] **Team Velocity** — Sprint-over-sprint velocity chart with story point tracking
- [ ] **Time Logging** — Per-task time entries with daily and weekly summaries
<!-- roadmap:postmvp:end -->

## Future

<!-- roadmap:future:start -->
- [ ] **Notifications** — In-app and email notifications for task assignments and due dates
- [ ] **API Webhooks** — Outbound webhooks for task state changes and sprint events
<!-- roadmap:future:end -->

## Deferred

<!-- roadmap:deferred:start -->
- [ ] **Mobile App** — Native iOS/Android client consuming the REST API
<!-- roadmap:deferred:end -->
