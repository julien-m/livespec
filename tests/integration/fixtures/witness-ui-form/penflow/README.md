# Local form Penflow producer

Read the [witness contract](../contract.md) for the accepted behavior. Run the independent
[capture producer](../../../helpers/witness_penflow.py) after generation to collect actual
browser DOM, visibility, geometry, empty-submit and valid-submit observations. Its raw
packet is runtime evidence; it does not declare C51 certification.

The producer calls the installed Penflow source-authority API, implementation run and
report revalidation. Each command and exit/output is saved outside the candidate. An
authenticated source inventory permits an independently generated build manifest inside
the candidate's dedicated runner directory, outside its Penflow workspace; an external
receipt binds those exact bytes. The evaluator still requires current C51 certification.

Read the [proposed form contract](form-contract.json) for a reproducible capability probe,
not an approved design baseline. It declares the actual input edit and local submit,
without requests, permissions or durable storage. Earlier Penflow versions required
fictional request semantics for that submit; the producer probes the installed validator
and names that exact compatibility gap when present. Current Penflow supports the local
submit prerequisite. The producer never fabricates Pencil persistence/vision evidence.

Native Pencil tools and actual native persistence were verified during implementation.
An isolated source review caught a missing exact submission-count predicate before
approval; a corrected source review and native C45/C46 design certification then passed.
These observations do not turn the proposed contract into a reusable certified baseline.
Repeat approved source review, native design production and runtime outcome capture for
the selected scope; frozen fixture data cannot replace those executed stages.

Run the [runtime translator](../../../helpers/witness_penflow_runtime.py) through the
capture producer to derive C12 geometry and five typed C51 observations from browser
measurements. It retains actual input/click/submit events, empty and edited snapshots,
submission counts and observed screen state. Missing DOM action mappings fail explicitly;
expected predicates never supply observed values. Each observation binds its measured
facts and original browser packet to the independent build manifest. Current cumulative
Penflow validation remains the authority for the resulting implementation verdict.

A real isolated trial completed the cumulative implementation profile after one model
repair against the unchanged native design: all eleven obligations passed. Independent
recaptures rejected missing required validation, a duplicate submit and incorrect button
width. Restoring the generated bytes and recapturing produced a fresh implementation
PASS. This is an observed trial, not a certificate copied into subsequent candidates;
each candidate still requires its current source, native and runtime authority.
