## Vision

**What the project does:**
LiveSpec is a universal, tool-agnostic specification framework for AI-driven development. It combines a Markdown-based command system (Claude Code slash commands + agents) with a Python CLI validator (`livespec-validator`) that enforces 4 structural layers on `.specs/` directories: Layer 1 schema validation, Layer 2 cross-file coherence rules, Layer 3 SDK-isolated integration checks, and Layer 4 LLM-based semantic validation (scorecard, contradiction detection, plan review).

**The core problem it solves:**
Specs are throwaway documents — written once, never updated, no traceability between requirements and actual code. LiveSpec makes specs living artifacts: every requirement links to a `@spec` anchor in code, every change is logged in per-feature changelogs, and the validator enforces structural integrity at commit time via a pre-commit hook.

**Success in 2 years looks like:**
LiveSpec is the default spec framework for Claude Code projects. The Python validator runs in CI on thousands of open-source and commercial projects. A single `/spec-feature` invocation ships a fully-specified, tested, and traced feature end-to-end.
