### Adaptive project detection

`migrate-visual-tests.js` now auto-detects project structure at startup:
- `hasFrontendE2E = existsSync('frontend/tests/e2e/')` → frontend/Pencil mode
- `hasPencilMockups = existsSync('.specs/design/screens/')` → Pencil mockup mode
- `hasFrontendConfig = existsSync('frontend/playwright.config.ts')` → update that config

**Frontend/Pencil mode** (active when `frontend/tests/e2e/` exists):
- `TEST_DIR = 'frontend/tests/e2e'`
- `MOCKUP_DIR = '.specs/design/screens'`
- `CONFIG_PATH = 'frontend/playwright.config.ts'`
- New E2E template with `toMatchSnapshot(mockupPath)` + `console.warn` fallback
- `inferMockupFilename()` searches for `current-NN-*{slug}*-{viewport}.png`
- `cleanupOldMigration()` removes `playwright.visual.config.ts` and root `baselines/` dirs

**Legacy mode** (fallback when no `frontend/tests/e2e/`):
- Unchanged: `tests/visual/` + `playwright.visual.config.ts` + `baselines/mockups/`
- Existing behavior preserved
