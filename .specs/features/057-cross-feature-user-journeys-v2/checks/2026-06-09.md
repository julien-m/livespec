# Spec Fix Report - Native Compiler Completeness

**Checked:** 2026-06-09  
**Feature:** `.specs/features/057-cross-feature-user-journeys-v2/`  
**Command:** `$spec-fix 057-cross-feature-user-journeys-v2`  
**Goal hash:** `2dc20b6bf9cdd20957aa042a055f5362c5a33b8687d2be8056a3f7a714e9e426`

## Verdict

**Overall health:** Fixed for the LiveSpec compiler findings surfaced by the Strapt audit.

The audit showed generated Swift and manifest outputs that were incomplete or formatting-blocking. The source defect is LiveSpec feature 057 because the compiler wrote native artifacts even when runner actions were unsupported.

## Gaps Closed

| Gap | Previous Status | Current Status | Evidence |
|---|---|---|---|
| GAP-004 - Unsupported native steps emitted as comments | Blocking | ✅ Fixed | `validator/journeys/capabilities.py` now rejects unsupported and malformed runner actions before output; `tests/test_journey_v2_compiler.py` proves XCUITest `wait` and malformed step payloads do not write Swift. |
| GAP-005 - Generic XCUITest `testJourney` names | Minor | ✅ Fixed | `validator/journeys/compiler.py` emits `test<JourneyId>Journey()`; compiler test asserts no generic `testJourney()`. |
| GAP-006 - XCUITest assertions used narrow/static text lookup | Major | ✅ Fixed | XCUITest target lookup uses `app.descendants(matching: .any)["<identifier>"]` for stable IDs and text fallbacks. |
| GAP-007 - Supported XCUITest fill/assert_not/open lacked concrete code | Blocking | ✅ Fixed | Compiler emits `typeText`, `XCTAssertFalse`, URL-only `xcrun simctl openurl booted` deep-link commands, timeout handling, Foundation import, and screenshot attachments for supported inputs. |
| GAP-008 - Manifest JSON lacked trailing newline | Nit | ✅ Fixed | `write_compiled_manifest()` writes formatter-friendly JSON with a final newline; compiler test checks bytes end with `\n`. |

## Fix Plan Executed

1. Extend runner capability validation from runner-only checks to per-action checks before native artifact writes.
2. Generate concrete XCUITest code for supported actions: open, click, assert, assert_not, fill, screenshot, and back.
3. Keep unsupported condition-free waits, malformed step dictionaries, missing target/value payloads, and XCUITest non-URL `open` inputs out of generated native output by returning `journey_capability_unsupported`.
4. Add regression tests for unsupported-action rejection, malformed payload rejection, named XCUITest methods, concrete fill/assert_not/open/screenshot output, simctl timeout handling, and manifest trailing newline.
