## Proven gap

[`write_owned_temporary()`](../../../../validator/goal_archive_file.py) opens an exclusive temporary file, records `(st_dev, st_ino)`, and then closes the descriptor through `os.fdopen(...)` before returning that tuple. [`_write_confined_artifact()`](../../../../validator/goal_archive_fd.py) later uses only the tuple to authorize publication and cleanup.

On Linux, after an attacker or racing process unlinks the owned temporary path, the closed inode can be reclaimed. A replacement created at the same path can receive the same `(st_dev, st_ino)`. The stale tuple can therefore authorize publication or deletion of an unowned replacement. The two CI failures exercise publication and cleanup sides of this same lifetime defect.

## Minimal correction and invariants

1. Return an ownership handle containing a **live file descriptor** and its initial identity, for example `OwnedTemporary(fd, identity)`. Ownership transfers to the caller only after write, flush, and `fsync` succeed.
2. Keep the owned descriptor open while writing, pre-publication validation, no-replace publication, post-publication validation, and residue cleanup run. If a text stream wraps it, use `closefd=False` or a duplicated stream descriptor so the ownership descriptor remains live.
3. Derive the authoritative identity with `os.fstat(owned_fd)` while the descriptor is live. Compare every visible temporary/final entry against that live identity before acting. A still-open descriptor pins its inode, so unlink/recreate cannot impersonate it through inode reuse.
4. Close the ownership descriptor exactly once in an outer `finally`, after any success cleanup or failure cleanup. Construction/write failures must clean while the descriptor is still live, close it, and re-raise. Publication, post-check, and cleanup failures must follow the same close guarantee.
5. Preserve the existing cooperative lock, exclusive link publication, outcome semantics, and the documented non-cooperative check-to-unlink race boundary. No rename-overwrite behavior or broader archive redesign is needed.

## Required regression proof

- Keep both failing Linux replacement tests and require: foreign temporary preserved, final artifact absent, blocked result retained.
- Add descriptor-lifetime assertions for success, blocked-before-publication, write failure, publication failure, post-check failure, and cleanup failure. Capture the descriptor passed through the helper and verify `os.fstat(fd)` raises `EBADF` after the public operation returns or raises.
- Prove cleanup compares against the live owned descriptor before deletion and that every exception path closes it exactly once.
