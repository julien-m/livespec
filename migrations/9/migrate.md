# Migration v9: README Status Audit

Older `.specs/README.md` files often contain stale `Status` values
(features stuck at `Draft` or `Planned` after their `implementation.md`
was created, or after code merged outside the `/spec-implement` flow).
Likewise, the `Recent Activity` table was only regenerated by
`/spec-implement` and `/spec-stack`, so projects that ran many
`/spec-specify` in a row had a Recent Activity stuck weeks behind the
actual changelog.

This migration walks every `features/NNN-…/` directory and rewrites
the `Status` column from artifacts on disk:

- `implementation.md` present → `Implemented`
- `plan.md` present (no `implementation.md`) → `Planned`
- spec only → `Draft`

It also rewrites the block between
`<!-- readme:activity:start -->` and `<!-- readme:activity:end -->`
with the last 10 entries from `.specs/changelog.md`.
