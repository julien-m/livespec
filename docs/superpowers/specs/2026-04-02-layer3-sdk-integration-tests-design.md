# Design: Layer 3 — SDK Integration Tests

> Integration test framework for LiveSpec using Claude Code SDK.
> Date: 2026-04-02

---

## Overview

Three-tier test architecture:
- **3A**: Structural invariants on static fixtures (no LLM, $0, <60s)
- **3B**: Isolated commands via SDK (nightly, ~$20/run)
- **3C**: Full pipeline end-to-end (release gate, ~$80/run)

## Structure

```
tests/integration/
├── conftest.py              # Session fixtures, env checks, markers
├── helpers/
│   ├── assertions.py        # Reusable assertion helpers
│   ├── sdk_runner.py        # Claude Code SDK wrapper
│   ├── validators.py        # Structural validators (frontmatter, sections, etc.)
│   └── cost_tracker.py      # Token/cost tracking per run
├── fixtures/
│   ├── minimal-app/         # Bare TypeScript project
│   ├── post-init/           # Project with .specs/ initialized
│   ├── post-specify/        # Project with feature spec created
│   └── broken/              # Corrupted fixtures for chaos tests
├── test_property_invariants.py  # Level 3A
├── test_spec_init.py            # Level 3B
├── test_spec_specify.py         # Level 3B
├── test_spec_plan.py            # Level 3B
├── test_spec_feature.py         # Level 3C
├── test_non_regression.py       # Level 3B
└── test_chaos.py                # Level 3B (chaos)
```

## Key Decisions

- 3A tests use Layer 1+2 validators directly (Python native)
- 3B/3C tests use claude-agent-sdk (optional dependency)
- Budget guard: auto-stop at 90% of LIVESPEC_TEST_BUDGET_USD
- Static fixtures committed; regeneration script for updates
- CI: GitHub Actions with 3 separate jobs
