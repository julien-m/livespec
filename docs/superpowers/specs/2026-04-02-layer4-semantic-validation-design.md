## Overview

LLM and embedding API calls are stubbed with clear interfaces for future integration. Scorecard axes 1-3 (structural) are fully functional using Layer 1+2 data.

4. **Mutation testing** — catalogue + runner framework
5. **Multi-model** — behind --experimental flag (stubbed)
