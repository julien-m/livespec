# spec-implement

Read [review led delivery](../../../system/review-led-delivery.md) before acting. Resolve this link from this skill's real directory when installed through symlinks. This is the default for direct, nested, autonomous and resumed work; no extra flag selects it.

Treat [the former certification workflow](certification.md) as an explicit historical diagnostic only. Do not load or execute it during normal delivery. Historical CLI checks keep their real verdicts and never become automatic delivery prerequisites.

## Work

1. Resolve the existing feature and read its spec, plan, decisions, project context and applicable conventions.
2. Implement the scoped change. Use targeted checks during coding and retain their true outcomes; no mandatory RED/GREEN receipts, conventions certificate or Penflow certification.
3. Run one independent final review under the shared policy, or return the implementation and checks to the owning feature coordinator for that same review. Do not add a second review when the parent owns final delivery.
4. Correct findings, recheck affected behavior and update implementation mappings, changelog and status honestly.
