# spec-check

Read [review led delivery](../../../system/review-led-delivery.md) before acting. Resolve this link from this skill's real directory when installed through symlinks. This is the default for direct, nested, autonomous and resumed work; no extra flag selects it.

Treat [the former certification workflow](certification.md) as an explicit historical diagnostic only. Do not load or execute it during normal delivery. Historical CLI checks keep their real verdicts and never become automatic delivery prerequisites.

## Work

1. Resolve the requested scope and read the specification, plan, changed code and applicable conventions.
2. Inspect behavior, file placement, architecture, acceptance coverage and relevant actual check results. Use the shared final review contract when this is the independent review of a delivery.
3. Report concrete findings with their impact and file references. Distinguish material defects, minor observations, failed checks and missing essential observations; do not turn missing certificates into product defects.
4. Stay read-only unless fixes were explicitly requested. Return the review directly without machine receipt ingestion or nested goals. Do not request another review merely to certify this review.
