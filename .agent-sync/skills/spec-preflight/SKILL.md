# spec-preflight

Read [review led delivery](../../../system/review-led-delivery.md) before acting. Resolve this link from this skill's real directory when installed through symlinks. This is the default for direct, nested, autonomous and resumed work; no extra flag selects it.

Treat [the former certification workflow](certification.md) as an explicit historical diagnostic only. Do not load or execute it during normal delivery. Historical CLI checks keep their real verdicts and never become automatic delivery prerequisites.

## Work

1. Read the requested operation and relevant tool requirements. Check the tools, permissions, credentials availability and disk capacity needed for it without exposing secrets.
2. Report available and unavailable capabilities with the exact action affected. Continue independent work; a missing optional checker is not a feature stop.
3. Repair local reversible setup within authorization when requested. Never bypass an explicit tool refusal or invent access.
4. Return a compact prerequisite report to the owning agent. Do not add a preflight goal, receipt, certification or repeated full-environment check.
