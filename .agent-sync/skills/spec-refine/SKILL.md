# spec-refine

Read [review led delivery](../../../system/review-led-delivery.md) before acting. Resolve this link from this skill's real directory when installed through symlinks. This is the default for direct, nested, autonomous and resumed work; no extra flag selects it.

Treat [the former certification workflow](certification.md) as an explicit historical diagnostic only. Do not load or execute it during normal delivery. Historical CLI checks keep their real verdicts and never become automatic delivery prerequisites.

## Work

1. Resolve the target and read the current text, implementation context and accepted user decisions.
2. Clarify the requested edit and preserve requirement identities and unrelated behavior. A technical/documentary correction needs no new functional approval.
3. For an actual functional change obtain the necessary user decision, update the relevant specification and plan, and include the change in plan/final review as appropriate.
4. Show the diff and update the changelog. Keep existing historical reviews intact; no revision-open, revision-close, continuity record or proof reclassification is required.

Honor read-only or preview requests. Refine may update an in-progress feature within the user's authorized scope.
